- (decision) [ADOPTED] Design paradigm: Template Method on dc.omniReRank.provider.Base; concrete providers override 5 hooks. Base.Execute intentionally non-[Final] so signing-schemes (e.g. AWS SigV4) can override the sequence.
- (decision) [ADOPTED] Dispatch topology: single Engine (dc.omniReRank.Engine) mediates SQL surface, config load, provider resolution, and circuit breaker. Providers never see SQL callers or breaker state.
- (decision) [ADOPTED] Config storage: rerank config is a JSON sub-block under %Embedding.Config.Configuration.rerank (no new persistent class). Chosen at PRD Q1.
- (decision) [ADOPTED] Credential handling: rerank.apiKey holds the NAME of an Ens.Config.Credentials row; Base.ResolveApiKey returns the Password. Raw secret never appears in exceptions, logs, or return values other than the SetAuth header write.
- (decision) [ADOPTED] Circuit breaker topology: per-namespace persisted global ^omniReRank.Breaker(providerKey)=$LB(failures,openedAtSeconds); key=provider|modelName; threshold=5; cooldown=60s; half-open on first call after cooldown; explicit $LB(0,0) on success.
- (decision) [ADOPTED] Retry: Base.RetryWithBackoff retries 429+5xx only; fast-fails other 4xx; honors numeric Retry-After when honorRetryAfter=1; defaults maxAttempts=3, baseDelayMs=500, maxDelayMs=8000; all overridable via rerank.retry.*.
- (decision) Provider resolution: explicit rerank.provider only — no modelName-prefix inference (deliberate divergence from omniEmbedding). Enforces operator predictability.
- (decision) Result contract: RerankResult is a %SQL.CustomResultSet with columns (originalIndex INT, candidate VARCHAR, score DOUBLE) sorted DESC by score; originalIndex is 0-based into caller's candidatesJson.
- (decision) Score-space isolation: results from two providers MUST NEVER be merged in one result set. Fallback (v2) must fail over to one provider at a time; no blended ranking.
- (decision) Testability seams: (1) Base.PostOnce(request,url) wraps request.Post — subclass overrides for HTTP mocking. (2) ^||omniReRankCredential(name) process-private overrides ResolveApiKey. (3) ^||omniReRankProviderOverride(provider) process-private redirects Engine dispatch. All seams are process-private globals so production paths never accidentally trip them.
- (constraint) IRIS 2026 target; %Embedding.Config schema must expose EmbeddingClass, VectorDataType, VectorLength (open Q flagged in PRD).
- (constraint) %SQL.CustomResultSet on this IRIS build has Final %OnNew — use explicit SetRows(rows) initializer instead (learned during resilience-spec implementation).
- (event) spine finalized
